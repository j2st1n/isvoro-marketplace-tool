🌟 核心架构与功能特性

  • 科学剩余价值模型：精准到秒级计算剩余天数，折算周期实际剩余资费，自动识别 🎁 倒贴甩卖、平价转让 与 ⚠️ 高度溢价。
  • 6 维科学排序矩阵：倒贴最多、折扣最大、月均续费最低、日均成本最低、剩余流量最多及默认综合。
  • 1 亿权重被阻断 IP 沉底：智能三级探测流水线识别 [IP正常] 与 [IP被墙]，阻断机器直接累加 1 亿惩罚基数，无论何种排序绝对沉底。
  • 智能多维筛选器：一键 🚫 隐藏被墙机器、🎁 只看倒贴机器，支持 全部/月付/季付/半年付/年付 周期筛选。
  • Tailwind CSS HSL 双模自适应：无缝继承 Isvoro 原生 HSL 设计系统变量，亮暗色主题零硬编码完美融合。
  • 无侵入 CSS Order 排序：通过纯 CSS order 属性实现视图级重排，不触碰真实 DOM 树节点，保障 Vue 3 响应式生态零故障。
